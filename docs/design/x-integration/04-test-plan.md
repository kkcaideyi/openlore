# X RSS 接入测试计划

状态：计划，2026-10-24；本轮没有执行测试。对应 [实施设计](03-design.md)。

## 环境与材料

独立 `OPENLORE_DATA_DIR`，本地 Feed HTTP fixture，不连接真实群。准备脱敏 RSSHub 样本：正常帖、短帖、长帖、链接帖、引用帖、线程片段、转帖、HTML 标签、缺失时间、未来时间、重复 GUID、X/Twitter URL 别名、截断正文。

真实 P0 需要用户指定账号和已配置中间服务；凭据不进入样本或 Git。记录版本/digest、采样时间、配置中非敏感字段。真实 AI、测试归档仓库和测试群在端到端阶段明确目标后使用。

## 风险到验证映射

| 风险 | 验证层次 | 通过标准 |
| --- | --- | --- |
| RSS 只解析到摘要 | Python/TS 契约和样本测试 | 记录正文来源；只在 x_post 明确策略下接受已验证格式；普通 Feed 不变 |
| 短帖被误拦/伪造证据 | 准入与初审测试 | 实质短帖入池；不足证据长度的内容标记 insufficient，AI 调用为 0 |
| 标题等于正文 | 初审集成 | 规范化标题独立，真实正文可初审；纯标题/错误页仍拒绝 |
| 日期回源失败 | 采集集成 | x_post 使用来源日期且保持 verified:false；不发起 X HTML 补抓；缺失日期待复核 |
| X URL 别名导致重复 | SQLite 集成 | x.com/twitter.com 同 status ID 只建一篇文章，多来源关系保留 |
| XML 重排、GUID 变化 | 重复轮询 | 同一帖子连续拉取 10 次只入池一次，不重复排初审 |
| 候选失败后游标误推进 | 故障注入 | 未持久化候选前不确认来源状态；恢复后不漏掉已发现项 |
| 401/429/超时/错误 HTML | Feed 故障注入 | 来源报错、保留旧文章，不产生垃圾正文或假成功 |
| 私网例外扩大 | HTTP 单元/本地集成 | 仅允许精确 Feed 端点；跨源重定向、任意图片/原帖内网链接均拒绝 |
| DNS/大响应 | 可控 DNS 与流测试 | 拒绝未授权私网、绑定已检查解析结果；流式超限即终止 |
| 元数据随配置丢失 | 持久化与重启 | 版本元数据保持；普通历史文章默认策略不变 |
| Windows Python 无法启动 | 本机 smoke | venv Python 被正确定位，parse_feed 返回有效 JSON；POSIX 路径测试保留 |
| 研究或交付失败 | 已有链路回归 | 失败可见，未发布不计入完成；不声称本功能修复全部重启恢复 |

## 兼容、并发与回滚

运行既有 collection-quality、pool-admission、source-ingestion、assessment-evidence、processing-pool、research-first 和 pipeline-report 等相关测试，并完成 contracts/server/web 类型检查；Python 解析逻辑变化时运行其 pytest。

同源手动与定时抓取并发，确认 active 去重；不同源出现同帖只产生一个 canonical 文章。已 ready 帖发生修改时按首版“不覆盖”策略保留，不错误标榜版本追踪完成。

新字段默认值兼容旧来源。测试停用 X 来源并回退功能后的普通 RSS 流程；不通过删除业务数据达成回滚。

## 真实验证与验收

- 3 个来源，30 分钟轮询，连续观察至少 48 小时；Feed 请求成功率目标 ≥95%，所有失败有可查原因。
- 期间至少有一条可人工核对的新帖出现，否则只证明重复读取，不能验收增量能力。
- 对 Feed 实际返回的唯一有效帖子集合核对入池数、重复数及拒收原因；不把有限 Feed 窗口当作完整 X 时间线覆盖。
- 日期不被替换为采集时间；作者、原帖链接与帖文 ID 的抽样核对全部正确。
- 至少一条有研究价值的帖子走完初审、选文、研报和测试仓库归档；使用测试通知目标核对链接与标题。
- 零重复文章、零凭据进入日志或产物、普通 RSS 相关回归全部通过。

自动化测试通过与真实取数通过分别记录。产出验证记录：版本、环境、命令结果、计数、失败原因、脱敏示例及未覆盖项。若取数不稳定或正文常截断，返回选型阶段，不以本地 fixture 通过代替业务验收。
